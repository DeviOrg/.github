# Welcome to DeviOrg!

Welcome to the home of **Devi** — a multifunctional Discord bot built to make communities easier to manage, safer, and more enjoyable.

Our goal is to bring useful tools, automation, and smart features together in one place, giving Discord communities more flexibility and control over their servers.

Here you can find the source code of Devi, its official website, and the tools that power the project.

We're continuously working on improving Devi, refining existing features, and exploring new ways to make the experience better.
